Centro Interdisciplinario Ykére

Sitio web institucional desarrollado para el Centro Interdisciplinario Ykére, orientado principalmente a la atención de niños y adolescentes.

El proyecto fue diseñado desde cero con una estética moderna, cálida y profesional, incorporando elementos visuales lúdicos inspirados en la identidad del centro.

Tecnologías utilizadas
HTML
CSS
Bootstrap 
Bootstrap Icons
JavaScript puro
Google Fonts
Google Maps Embed

Bootstrap fue utilizado como apoyo para la grilla responsive, adaptación a diferentes dispositivos e iconografía, sin utilizar plantillas prediseñadas.

Características principales
Diseño responsive para escritorio, tablet y dispositivos móviles.
Navbar fijo con acceso directo a las principales secciones.
Botón de contacto directo mediante WhatsApp.
Sección de presentación institucional.
Áreas de atención:
Psicopedagogía
Psicomotricidad
Psicología
Fonoaudiología
Psiquiatría Infantil
Terapia Ocupacional
Presentación de la metodología de trabajo interdisciplinaria.
Sección de equipo profesional.
Visualización de convenios y modalidades de atención.
Integración con Google Maps y ubicación del centro.
Accesos directos a WhatsApp, correo electrónico e Instagram.
Animaciones suaves al hacer scroll.
Elementos decorativos animados realizados con CSS y JavaScript.
Diseño de ondas y degradados inspirado en la identidad visual de Ykére.
Footer informativo con datos de contacto y mapa.
Diseño

La propuesta visual combina tonos crema, azul, turquesa y detalles cálidos, buscando transmitir cercanía y profesionalismo.

Se utilizaron formas orgánicas, ondas, pequeños elementos gráficos y animaciones sutiles para generar una estética amigable para niños y adolescentes sin perder el carácter institucional del centro.

Objetivo del proyecto

El objetivo fue desarrollar una página web clara, accesible y visualmente atractiva que permita presentar los servicios del centro, facilitar el contacto con las familias y reforzar la presencia digital de Ykére.

Además, se trabajó con una estructura HTML semántica y buenas prácticas básicas de SEO para favorecer la correcta interpretación del sitio por parte de los buscadores.
